# Frontend deployment (Vercel)

## Framework
Vite + React

## Root directory
`frontend`

## Build settings
- Install: `npm install`
- Build: `npm run build`
- Output: `dist`

## Environment variables
- `VITE_API_URL` — public URL of the Render backend (e.g. `https://darukaa-ai.onrender.com`)

`vercel.json` is included for SPA rewrites.
